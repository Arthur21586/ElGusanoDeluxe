# ElGusanoDeluxe
El añadido "Deluxe" en el nombre indica que no es solo el juego básico tradicional, sino una edición ampliada y modernizada que incluye varios añadidos y mecánicas avanzadas.
Sistema de Niveles y Experiencia: Progreso estructurado (como el sistema de 1 a 10 o hasta 99 niveles) con requisitos de puntos para subir de categoría.

Tienda y Personalización: Desbloqueo de skins (Fuego, Hielo, Dragón, Oro), accesorios (sombreros, coronas, gafas) y efectos visuales para la cola del gusano.

Nuevas Mecánicas de Juego: Adición de power-ups (como la Super Velocidad ⚡ para duplicar puntos) y obstáculos dinámicos como las comidas venenosas (💀).

Sistema de Logros y Ranking: Un panel de metas para desbloquear y una tabla de puntuaciones locales o mundiales (TOP 10 Ranking) para competir por el récord más alto.
